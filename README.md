## 🛠️ Teknologi yang Digunakan
Proyek ini dibangun sepenuhnya menggunakan teknologi *front-end* dasar tanpa ketergantungan pada *server backend* atau *database* eksternal:
* **HTML5 & CSS3:** Membangun struktur kerangka web dan *styling* visual.
* **JavaScript (Vanilla):** Menangani logika interaksi pengguna pada halaman.
* **Bootstrap:** *Framework* CSS untuk memastikan tampilan web *responsive* dan rapi di berbagai ukuran layar (*mobile-friendly*).
* **Web Storage API (`localStorage`):** Menangani simulasi interaksi form. Data yang di-*submit* akan disimpan secara lokal di dalam *browser* pengunjung dan langsung dirender kembali ke antarmuka web.

## 🚀 Deployment & Hosting
Web statis ini telah di-*deploy* secara publik menggunakan **Cloudflare Pages**. Platform Cloudflare dipilih karena menyediakan distribusi CDN yang sangat cepat, aman, dan sangat cocok untuk *hosting* proyek *front-end* murni secara efisien.
